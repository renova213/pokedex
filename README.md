## 1. Installation & Running the App

This section describes how to set up the development environment and run a Flutter application.

---

### 1.1 Prerequisites

#### Ensure the following tools are installed on your machine:

- **Flutter (Stable channel)**
- **Dart 3+**
- **Git**
- **Melos**

#### Verify installations:

- flutter --version
- dart --version

### 1.2 Install Melos

- Install Melos globally:
- dart pub global activate melos
- melos --version

### 1.3 Bootstrap the Project, run this script in the root project

- melos bootstrap
- melos get
